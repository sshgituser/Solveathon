# Qolda / SerIQ — конкурсный прототип E02

**Готовый сценарий показа:** на Windows или в браузере выбрать короткий локальный MP4 с разгибанием локтя, дать согласие на обработку и увидеть нейтральный результат в дневнике. На контрольной станции оба клиента прошли этот путь с настоящей моделью A на NVIDIA GPU. Прототип не ставит диагноз, не измеряет боль и не даёт медицинских указаний.

## Как открыть и воспроизвести

- **На подготовленном ноутбуке:** открыть `windows/Qolda.exe` рядом с `engine-win64/`. Окно показывает «модель A готова». Если этот же движок работает на `127.0.0.1:8765`, его штатный Web-интерфейс доступен в браузере на этом адресе. `127.0.0.1` — адрес самого ноутбука, не публичная ссылка.
- **Из исходников:** [получение открытых данных и обучение A](TRAINING-ON-ANOTHER-PC.md) → [сборка и запуск Web/Windows](WINDOWS-FROM-SOURCE.md). Нужны Windows x64, NVIDIA/CUDA, Python 3.11 и FFprobe; для EXE также .NET 10 SDK при сборке и WebView2 Runtime при запуске. Данные и веса не входят в Git. Без них можно открыть ознакомительный интерфейс, но не получить настоящий результат.
- **Файловая проверка:** «Начать проверку» → «Видео» → выбрать свой или разрешённый клип с одним циклом → проверить локальный адрес в согласии → «Отправить на анализ» → «Дневник». Один и тот же файл не учитывается дважды; сцена без видимой руки не считается неудачным упражнением и не добавляет попытку. [Web-протокол](../reports/release/web-e02-canonical.md) · [протокол нативного Windows и переносимого движка](../reports/release/captain-acceptance.md).

## Что считает модель и что означают числа

RTMPose извлекает видимые ключевые точки, а обученный командой компактный TCN классифицирует последовательность движения. Данные разделены по добровольцам: 77 обучающих клипов и 20 validation-клипов от одного отдельного участника. Порядок классов в матрицах: `неполный, полный`; строки — разметка, столбцы — прогноз.

| Модель на том же development-validation | Balanced accuracy | Macro F1 | F1 полного цикла | Матрица |
|---|---:|---:|---:|---|
| E02/A | 1,00 | 1,00 | 1,00 | `[[10,0],[0,10]]` |
| Константный baseline: самый частый класс train («неполный», 47 из 77) | 0,50 | 0,3333 | 0,00 | `[[10,0],[10,0]]` |

Baseline вычислен из чисел классов, а не получен ещё одним запуском модели. Validation использовался при выборе модели; это не независимый test и не оценка клинической точности. Те же 20 клипов отдельно прошли упакованный файловый API; пустая сцена дала `no_pose`. [Агрегированная квитанция, версия и SHA](../reports/release/jury-e02-evidence.json), без записей участников, координат или поклиповых результатов.

| Android | ARM64 AAR и подписанный debug APK собраны. Автономный полный клип на телефоне не подтверждён; [рецепт сборки](ANDROID-FROM-SOURCE.md). |
