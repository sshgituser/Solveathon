# SerIQ · локальный HTTP-контракт v1

> Требования хакатонного прототипа, а не подтверждение готовности.

HTTP-контракт для Web и Windows, корень по умолчанию `http://127.0.0.1:8765`. Автономный Android сохраняет данные результата `version: "seriq.v1"` и коды отказа, но вызывает встроенный движок без HTTP и USB-туннеля; см. [Сценарий и инструкция по запуску](../SUBMISSION.md). Только локальный анализ: без публичной загрузки файла, телеметрии или постоянного серверного хранения.

Для проверки через локальный Web стандартный путь — открыть `/` на том же движке. Для отдельного статического сервера и отладки разрешены только определённые origin: `http://127.0.0.1:8080` / `http://localhost:8080`, соответствующие адреса с портом `5173`, а также `http://localhost`, `https://localhost` и `capacitor://localhost`. `OPTIONS` на запрос анализа допускает `POST` и `Content-Type`, на health — `GET`. Отдалённый хост пользовательского кабинета не получает доступа к API загрузки видео.

**GET /api/v1/health** → 200: `{ "version":"seriq.v1", "models":{"scratch":false,"transfer":false} }`. `true` означает, что адаптер действительно загрузил артефакт и может исполниться; наличие файла или живой HTTP-сервер этого не доказывает.

**POST /api/v1/analyze?model=scratch&mode=single**. `model`: `scratch` либо `transfer`, обязательное; `mode=single` — ровно одна заранее ограниченная попытка, без обещания распознать произвольное непрерывное занятие. Поддержка `continuous` объявляется отдельно после измерений. Тело — бинарный контейнер, не multipart, `Content-Type: video/mp4` или `video/webm`, `Content-Length` обязателен, минимум **1 байт**, максимум 64 MiB (67 108 864 байта), лимит длительности 30 секунд на анализаторе. Имя файла и путь передавать не требуется. `Cache-Control: no-store`; ответы не включают видео, координатные ряды, ID добровольцев или имена файлов.

200: `version`, `model`, `model_version`, `attempts` (список), `counts` (объект), `warnings` (строковые коды). Для попытки: `index` от 1, `label` (`complete`, `incomplete`, `uncertain`), `confidence` (0…1 или null), `reason` (null, `low_confidence`, `low_visibility` или `unscorable`). Для `uncertain` причина обязательна. Это уверенность классификатора, не вероятность болезни. `counts.total = complete + incomplete + uncertain = len(attempts)`. Полная потеря позы: HTTP 200, пустые attempts, нулевые counts, предупреждение `no_pose`; нет результата не значит incomplete. Неповторное добавление попытки в локальную сессию — ответственность клиента. Только модель и заранее зафиксированная политика качества создают успешные результаты.

Ошибки: JSON `{ "version":"seriq.v1", "error":{"code":"model_unavailable"} }`. 400 `invalid_request` (параметры), 411 `length_required`, 413 `too_large`, 415 `unsupported_media`, 422 `invalid_video` / `duration_limit`, 503 `model_unavailable` / `engine_busy`. Неизвестный маршрут — 404 `not_found`. Отказ в доступе источнику — 403 `forbidden`. Сырые исключения/пути в UI не возвращать. Пример запроса с разрешённым собственным клипом: `curl --data-binary @one-cycle.mp4 -H "Content-Type: video/mp4" "http://127.0.0.1:8765/api/v1/analyze?model=scratch&mode=single"`.

Примеры в `fixtures/contracts/` — только тест обмена, не результаты модели. Реализация загружает локальный артефакт и extractor по хэшам: историческое воспроизведение — по `reports/ml/forearm-v1/freeze.json`, текущая поставка — по приватному `seriq-bundle-v1`. Загрузчик требует `source_commit` в формате 40 строчных hex-символов (проверка формата, не подпись происхождения) и `runtime.device_class = "nvidia-cuda"`. Сборщик записывает `model.slot`; у совместимого старого bundle с незаданным слотом `scratch` выводится только для standalone A (`id`/`variant` = `A`, без SLiM-базы). В текущем строгом пути `scratch` принимает только такой A, `transfer` не регистрируется. Если bundle не прошёл проверку, сервер поднимается без моделей: `health` показывает `false`, поддерживаемый запрос анализа отвечает 503 `model_unavailable`. В `seriq-e02-forearm-2d-v1` `confidence` — некалиброванный нормированный отступ от порога, не вероятность правильности или медицинский показатель. Отступ ниже 0,10 даёт `uncertain`; когда нет кадров с одновременно видимыми локтем и запястьем, возвращается `no_pose` без зачтённой попытки.
