# SerIQ · интерфейс v1 для трёх клиентов

> Требования хакатонного прототипа, а не подтверждение готовности.

Один сценарий: язык → инструкция (собственное или разрешённое видео + субтитры) → «Выбрать видео» или «Записать один цикл» → явное согласие, где проходит обработка → результат → локальная сводка. Кнопка «Отмена» доступна до отправки; важные действия доступны с клавиатуры, читабельны крупным шрифтом и не зависят только от цвета. Копии RU/KK проверяет носитель перед защитой.

| Сигнал API | Что видит человек | Что учитываем |
|---|---|---|
| `complete` | Выполнено / Орындалды | +1 complete |
| `incomplete` | Проверьте инструкцию / Нұсқаулықты тексеріңіз | +1 incomplete |
| `uncertain` | Не удалось уверенно оценить. Посмотрите инструкцию ещё раз. | +1 uncertain, не incomplete |
| `no_pose`, пустой список | Рука не видна достаточно хорошо для оценки | Нет засчитанных циклов |
| 503 | Анализатор недоступен; подключите локальный движок | Ничего не добавлять |
| сброс / повтор того же запроса | Подтвердить удаление / не дублировать результат | Только локальная сводка |

Разрешение камеры необязательно для выбора файла. Никаких подсказок «согните сильнее», оценок боли, диагнозов, норм лечения и скрытой отправки в сеть. Сводка по умолчанию живёт на устройстве (в памяти сессии), без имени, идентификатора пациента и видео. Переключение моделей для сравнения не добавляет второй физический цикл. Демо-фикстура с заранее известным ответом не используется вместо работающего анализа.

Кабинет прототипа — **локальный профиль**, не медицинский аккаунт. Псевдоним необязателен и не участвует в анализе. Локальные настройки интерфейса могут сохраняться отдельно; попытки и самоотметка «насколько легко давались движения» сохраняются на устройстве только по явному выбору. Самоотметка не поступает в HTTP API анализатора, не влияет на класс и не является шкалой боли. Если сервер истории недоступен или ещё не реализован, клиент не пишет «синхронизировано». Передача не нужна для основного локального пути.
