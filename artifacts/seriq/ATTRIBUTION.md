# SerIQ E02 — provenance

No upstream model weights, input recordings, extracted skeletons or per-clip predictions are distributed here. If a local fit succeeds, the A safetensors file contains only the new TCN parameters; the B safetensors file contains only the fine-tuned last block and new binary head, overlaid on the original checkpoint at load time. A test-only parameter update is not a trained dataset artifact.

For the separately versioned `seriq-e02-forearm-2d-v1`, both local classifiers use only the observed image-plane right-labelled elbow and wrist, with the projected track centered and scaled once per clip. The official pretrained SLiM checkpoint and trained A/B packages remain private; the report records their hashes, not model or clip contents.
