# Безопасность и приватность

Qolda — локальный конкурсный прототип, а не публичный сервис обработки видео. Не выставляйте loopback-API в интернет и не используйте прототип для медицинских решений. [Описание архитектуры](docs/ARCHITECTURE.md) · [границы фактической проверки](reports/security/current-release-privacy.md).

## Как сообщить о проблеме

Если в GitHub доступна функция **Security → Report a vulnerability**, отправьте приватный отчёт через неё. Если нет — обратитесь к владельцу репозитория приватно. Не создавайте публичный issue с уязвимостью, доступом к частным сборкам или информацией о человеке.

Достаточно указать SHA Git, платформу, версию сборки, ожидаемое и фактическое поведение. Для воспроизведения используйте синтетический вход без людей и удалите из лога персональные пути и идентификаторы. **Не отправляйте** видео людей, покадровые координаты, клиповые хэши, дневники, ключи, токены или дампы устройства.

Если обнаружена чужая запись или секрет в истории Git, не распространяйте их и не цитируйте содержимое; сообщите только идентификатор ревизии и тип проблемы приватно.
