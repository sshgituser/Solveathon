# Qolda / SerIQ E02 · проверка локальной интеграции

**Windows нативно, без WSL.** Использован Web-клиент Димаса `62a70d83d6d2579d65147184f1800fc7d0ebc009`, проверенные локальные веса из [freeze](../ml/forearm-v1/freeze.json) и API v1. Это не release-кандидат трёх приложений и не клиническая проверка.

| Проверка | Наблюдавшийся результат |
|---|---|
| Зафиксированные веса и код ML | SHA-256 обеих моделей, pose-экстрактора, исходников и локального манифеста совпали с freeze; одноразовый lock совпал, holdout не переоткрывался. На прежней оценке обе модели 20/20 на одном добровольце; [ограничения](../ml/forearm-v1/README.md). |
| HTTP с обученными весами | `GET /api/v1/health` → 200, `scratch: true`, `transfer: true`. Каждая модель приняла два **development**-клипа; ответы 200 и по одному классу `complete`/`incomplete` на модель. Повторный успешный прогон: максимум 4,5 с для A и 4,3 с для B; в одном промежуточном прогоне клиент не дождался ответа за 25 с. Это проверка интеграции, не новая оценка качества или гарантия задержки. |
| Пропуски и плохой ввод | Синтетический клип без человека → `no_pose`, попыток 0 (MP4 и WebM). Видео 31 секунда → `422 duration_limit`. Невидео → `422 invalid_video`. Временный каталог загрузок после обработки пуст. |
| Web: реальный Chromium с чистым профилем | HTML/ES-модули/CSS/health → 200. Без модели отправка выбранного файла → 503, «Анализатор недоступен», 0 сохранённых попыток, 0 JS-исключений, 0 зарегистрированных внешних HTTP(S)-ответов. Этот браузерный прогон проверяет отказ; успешный инференс выше проверен через HTTP CLI. |
| Windows Desktop / Android | Данная проверка **не** устанавливала отдельный пакет или APK. Работа HTTP на Windows и браузерный прогон не равны запуску Windows Desktop либо проверке Android. |

Повторяемые команды и зависимости: `python -m unittest -q backend.test_api backend.test_contract backend.test_runtime tools.test_audit_data` (15 тестов), `python -m tools.smoke_web --chrome <chrome.exe> --scratch <scratch вне Git>` (Chromium, FFmpeg, Python `websockets`), в окружении ML `python -m tools.smoke_runtime --help` (принимает локальные пакеты A/B, RTMPose ONNX, SLiM base, E02 development и папку scratch). ML-suite: 30 тестов, в том числе паритет SLiM и re-load. Процедура не отправляет записи в сеть и не считывает holdout для инференса.

Сырые записи, скелеты, манифест отдельных роликов, обученные локальные checkpoint и внешние base-веса не входят в Git. В репозитории — хэши, код и агрегированные результаты; [атрибуция](../../artifacts/seriq/ATTRIBUTION.md).
