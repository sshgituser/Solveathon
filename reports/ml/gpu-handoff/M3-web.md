# M3 — Web на localhost: реальный прогон

Дата: 25.11.2026. Машина: Windows 11, RTX 5060 Ti. Движок: `backend.api` с приватным bundle
`A-gpu-dev-v1` (strict CUDA, поза + классификатор).

## Запись проверки

| Поле | Значение |
|---|---|
| URL | `http://127.0.0.1:8765/` |
| Браузер | Chromium, отдельный профиль браузера |
| Модель в UI | `scratch`, версия `seriq-e02-forearm-1.0.0+8dd234d4a3e1` |
| Путь | онбординг → «Проверка» → инструкция → выбор mp4 → согласие → «Отправить на анализ» |
| Разрешённый development-клип | UI вернул результат анализа и подтвердил добавление одной попытки в историю |
| Повтор того же файла | «Это видео уже учтено. Повтор не засчитан» — счётчик истории не вырос |
| Клип без видимой руки | «Рука не видна достаточно хорошо для оценки» — без «не выполнено» и без попытки |
| `GET /api/v1/health` | `{"version":"seriq.v1","models":{"scratch":true,"transfer":false}}` |
| Внешняя сеть | нет: 57 ресурсов, все `http://127.0.0.1:8765/` или `blob:` |
