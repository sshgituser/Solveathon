# Три кандидата для расширения C: что действительно можно перенести

Решение по публичной документации, без загрузки данных или запуска обучения. Для текущего [протокола B/C](../../../docs/model-intake-bc.md) ни один набор не даёт готовых размеченных циклов E02. Это вывод о совместимости разметки, не измерение качества моделей. Qolda оценивает завершённость одного движения во времени; в частности, траекторию связки локоть–запястье нельзя восстановить из аннотации одних пальцев и запястья. Не превращаем произвольные жесты в класс `incomplete` и не собираем «видео» из независимых фото.

**Следующий ход для конкурсной C:** оставить экстрактор, базу SLiM, бюджет шагов и собственную validation теми же, что для B; добавить только в train независимо записанные одобренные циклы E02 с видимыми локтем и запястьем, обеими метками и известными группами людей и исходных записей. Передача — по протоколу intake. Локализацию запястья исследовать отдельно и только после допуска источника: сначала установить на разрешённой development-части, что потеря запястья действительно ограничивает E02; сравнить исходный и изменённый экстрактор на одних и тех же записях. Изменение экстрактора не выдавать за эффект расширения корпуса классификатора. Закрытый holdout и карантин для этого не нужны.
