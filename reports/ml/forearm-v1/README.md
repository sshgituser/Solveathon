# SerIQ E02: локальная оценка forearm-only

Результат относится к записи E02 с наблюдаемыми локтем и запястьем, а не к измерению разгибания сустава. [Таблица метрик](experiment.md) · [агрегаты](experiment.json) · [freeze](freeze.json) · [лицензии и атрибуция](../../../artifacts/seriq/ATTRIBUTION.md).

## T-004: что наблюдается

- Строгая политика `seriq-e02-arm-triplet-v1` не менялась. MediaPipe Lite, MoveNet Lightning и RTMPose Body7 дали по **0/77 train и 0/20 validation** для полного плечо–локоть–запястье; причины сохранены в `reports/ml/coverage-*.json`. У RTMPose наблюдаемость правого плеча была 0.9% train и 0% validation. Для нового режима плечо не используется даже при видимости (на sealed test его RTMPose-маска была истинна справа во всех слотах). Legacy-режим на sealed test не оценивался.
- На train у детекторной правой пары 76/77 клипов имеют ≥40/64 совместно наблюдаемых слотов. При совместном наблюдении обеих меток стороны (2 220 слотов) максимальное расстояние соответствующих точек — 0.061 длины правого предплечья, медиана 0.021. Это согласуется с дублированием одного силуэта; две руки из этих меток не выводили. Вход — только правая метка RTMPose, без переключений и переноса левых точек в пропуски. Метка стороны экстрактора не является независимым подтверждением анатомической стороны.
- Размер правого сегмента (медиана на клип) 0.186–0.324 доли длинной стороны кадра. На train медиана поклиповых P90 межслотовых шагов больше двигающегося конца — 0.043 длины предплечья, максимум 0.071. Медианный размах движения относительно длины — 0.763. Нормируем одной трансляцией и одним масштабом на клип, а не на каждом кадре. Поэтому движение обоих концов и поворот в плоскости сохраняются; масштаб не считается измерением в метрах.
- Нужны минимум 40/64 пригодных слотов, ≥6/16 в каждой четверти. Фильтруются проекционные длины вне `[0.60, 1.45]` медианы, >6 выбросов длины или скачок больше `min(0.20×шаг_в_слотах, 0.55)` медианных длин блокирует клип. Стабильный отделённый кандидат другой стороны (>0.45 медианной длины в ≥8 слотах) вызывает отказ как неоднозначность, а не склейку. Слишком статичный трек (P10–P90 смещение <0.10 длины у обоих концов) блокируется. Для коротких входов повторов и заполнения нет; `z` и маски углов пусты. Правила заданы отдельно от confidence детектора. Кадры, FPS, идентификаторы, имена и длительность не передаются классификатору.
- Фактически после фильтров: train **71/77** (`incomplete_forearm_coverage`: 5, `insufficient_visible_forearm_pair`: 1; 42/47 `incomplete`, 29/30 `complete`); validation **20/20**; test **20/20**, 0 отказов, 1 280 пригодных правых слотов. В train/validation было ровно 97 изолированных кэшей; сверены SHA всех 97 исходных файлов, число нативных кадров ≥64 и общий хэш кэша. Четыре повторных прямых извлечения *только из development* совпали с `.npz` побитово по координатам и маскам. В sealed-кэше ровно 20 отдельных записей; карантин не использован.

## T-005/006/011: результат и что он не доказывает

| | A: TCN с нуля | B: NTU60 XSub SLiM + дообучение |
|---|---:|---:|
| Seed; шаги; выбранная эпоха | 601; 324; 36 | 602; 180; 20 |
| Параметры обучаемые / всего | 2 321 / 2 321 | 794 465 / 6 369 025 |
| Изменившиеся тензоры | 8 | 12 последнего блока + 2 головы; 92 других проверены неизменными |
| Порог | 0.50 | 0.50 |
| Validation и sealed test | каждый 20/20, BA / macro-F1 / F1 complete = 1.00 / 1.00 / 1.00 | то же |
| Матрица на каждом held-out split | `[[10,0],[0,10]]` | `[[10,0],[0,10]]` |
| Полноразмерный balanced recall: train / validation / test | 0.9301 / 1.0000 / 1.0000 | 0.9301 / 1.0000 / 1.0000 |
| Test: низкий margin / ложные уверенные complete | 0 / 0 | 0 / 0 |

Строки и столбцы матриц: `incomplete`, `complete`. Оба артефакта прошли перезагрузку на CUDA: delta `p_complete = 0` на 20 validation; CPU public API отдельно воспроизвёл 20 validation и правильные отказы на wrist-only. На CPU также прошёл дымовой тест прямого локального видео для обеих классовых меток development. Тесты: 30 passed; 6 ожидаемых предупреждений upstream о выключенном xFormers. Обучение последнего блока подтверждено SHA исходного и выбранного `encoder.blocks.7.attn.qkv.weight` в JSON. Первые семь блоков B вычислялись в `eval` для фиксированного входа; последний блок участвовал в backprop вместе с головой. Разные архитектуры не дают выделить чистый эффект предобучения. **B не превзошёл A**; для локального прототипа можно предпочесть A: она проще, компактнее и не требует upstream-файла.

Контроль на одних масках (ridge, обучение на train, порог по validation): BA 0.55, macro-F1 0.436 на validation. Конкурирующее объяснение через одни пропуски стало слабее, но это не исключает зависимости от траектории камеры, съёмочной постановки, ракурса, стадии монтажа или различий в инструкциях. Соединение локоть–запястье не определяет угол без направления плечо–локоть, даже при идеальном детекторе. Нет доказательства, что обработана вся попытка, а не её видимый фрагмент. Не заявлять результат для клиники, нового положения камеры, другой руки, другого добровольца или непрерывной записи. Validation и test — по одному отдельному добровольцу. Официальный бриф, §1.3, допускает последовательность координат **или** углов; этот вариант не заменяет отдельную демонстрацию наблюдаемости полной тройки, если она нужна внутренней спецификации.

## Команды фактического прогона

Из корня worktree в Git Bash. `$private` — приватная директория `seriq-local` вне Git; `$root` — локальный E02. `ml/manifest.json` — ранее созданный игнорируемый локальный инвентарь, можно указать его приватную копию с тем же SHA. Установка среды, веса и генерация нового инвентаря — в [`ml/README.md`](../../../ml/README.md). Имена `reports/ml/forearm-v1` и `$private/forearm-v1-artifacts` относятся к уже завершённому прогону. Для этой конфигурации после вскрытия блокируются и `fit`, и `test` независимо от директории вывода; не удаляйте lock. Для нового исследования заранее зарезервируйте независимую группу.

```bash
pose=("$private"/rtmpose/*/*/*/end2end.onnx)
slim="$private/slim-ntu60-xsub.safetensors"
seriq() {
  "$private/.venv/Scripts/python.exe" -Bu -c 'import os,sys,runpy; h=os.add_dll_directory(sys.argv.pop(1));runpy.run_module(sys.argv.pop(1),run_name="__main__")' "$private/msvc" "$@"
}
export SERIQ_SLIM_BASE="$slim" SERIQ_SLIM_SRC="$private/upstream-slim" SERIQ_CHECK_DEVICE=cuda
seriq pytest -q -p no:cacheprovider ml/tests --basetemp "$private/pytest-forearm-full"
opts=(--root "$root" --private "$private" --manifest ml/manifest.json --engine rtmpose
      --pose-model "${pose[0]}" --slim-base "$slim" --pose-policy seriq-e02-forearm-2d-v1
      --artifacts "$private/forearm-v1-artifacts" --reports reports/ml/forearm-v1 --device cuda)
seriq ml.train fit "${opts[@]}"
# Ниже — запись уже выполненной однократной команды, не повторять:
# seriq ml.train test "${opts[@]}"
```
