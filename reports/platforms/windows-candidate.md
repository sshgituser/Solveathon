## Запуск на другом ПК и границы проверки

Распаковать ZIP рядом с `engine-win64/` и открыть `windows/Qolda.exe`. Оболочка либо использует уже готовый совместимый процесс на `127.0.0.1:8765`, либо на отказе соединения один раз запускает поставленный Python со строгим bundle; кнопка «Подключиться» только перепроверяет доступность. `qolda.local.json` (не в Git и не в ZIP) может переопределить пути `backendRoot`, `python`, `bundle`, `artifacts`, `poseModel`, `ffprobe`, `scratch`, `dllDir`. Относительные пути разрешаются от конфигурации или каталога EXE, отсутствующие файлы перечисляются без раскрытия их абсолютных путей. При недоступной модели работающий интерфейс остаётся доступен, нативная строка состояния показывает ошибку; подставных результатов и CPU fallback нет. Системный выбор файла предоставляется общим фронтендом; камера для этого кандидата выключена.

**Не проверено в этом запуске:** повторное подключение к уже работающему backend, ветки отсутствия/повреждения модели или конфликта порта, фактический выбор и анализ MP4/WebM с согласием, отдельный сетевой аудит/запуск с отключённой сетью и чистый ноутбук.
