## 4. `local` vs `connected`: что включает и что скрывает профиль

| Возможность | `local` (сейчас в `index.html`) | `connected` (возможность в коде) |
|---|---|---|
| Анализатор | `loopback`, адрес по умолчанию `http://127.0.0.1:8765` | `remote`, адрес из `<meta name="seriq-api">` |
| Поле адреса в кабинете | **показано**, можно менять | **скрыто** (`engineSettings:false`); остаются текст-подсказка, кнопка «Проверить связь» и статус |
| Модель по умолчанию | показана | показана |
| Профиль/история/дневник | локально; запись на диск только при `persist` | тот же локальный слой; сервер истории не реализован |
| `account` | `false` | `true` **в объекте профиля, но ни один экран это поле не читает** |
| `installHint` | `false` | `true` **в объекте профиля, но ни один экран это поле не читает** |
| Регистрация/вход | отсутствует | **отсутствует** |
| Синхронизация сайта и телефона | отсутствует | **отсутствует** |
| Сеть | CSP только loopback | нужен внешний сервис; в репозитории его нет |

Важно: `connected` **не** скрывает кабинет, статистику, историю, экспорт или удаление. Он скрывает только редактирование адреса анализатора; `account`/`installHint` — пока мёртвые флаги. Если принудительно выставить `seriq-analyzer=ondevice`, `analyzer.js` возвращает `notBuilt`: health `down`, анализ `503 model_unavailable`.
