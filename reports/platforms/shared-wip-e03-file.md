- `verify_apk.py --require-wired-frontend` прошёл. Дополнительно **75/75** файлов из `frontend/src`, `frontend/styles`, `assets` внутри APK побайтово совпали с Git blobs выбранной ревизии; `android/bridge.js` сверён отдельно. Это больше, чем наличие файла-моста; но это всё ещё статическая проверка, не телефонный прогон.

Эту сборку нельзя пометить `whole_clip`, `physical_camera` или `offline_e2e` по результатам прошлого APK. Замена пакета — с согласия владельца; выключение сети и отключение кабеля выполняет владелец. Дополнительный раздел общего UI — отдельная незавершённая работа.

## Дополнительные упражнения: что доступно

**E03 (запястье)**: принят **только локальный Web file API для development-демо**; не физическая камера, не UI, не Windows-приёмка, не Android и не клиническое применение. Из неизменных весов `95abbe0a8c77b36d9f319648a6f49490d77600c42479b18d14500cfcaac6f822` и `model.json` создан отдельный приватный model root `deliverables/extra-file-dev-e03-v1/`, с `E03/run/promotion.json` (SHA-256 `fcad0a1704d3702e52eee4e37f73e209ffd0e19097d4ac7aa41fd34ad8f40c76`). Исходный run обучения не изменялся. Для нового запуска предоставить backend **корень**, не `E03/run`, через `--extra-model-root`, плюс `--private-scratch` и `--ffprobe`. Требуется backend не старее `fdbf643`. Не перезапускали существующий сервер на 8870, там эти маршруты не объявляем действующими.

В отдельном одноразовом loopback-обработчике использованы обычные `GET /api/v1/exercises` и `POST /api/v1/exercises/E03/analyze`, реальный FFprobe и строгая CUDA-фабрика; не подменяли кадры, веса или ответы. Каталог: E03 `web.file:true`, `web.live:false`, остальные платформы `false`; E01 не зарегистрирован. Взято по первому заранее определённому разрешённому validation-клипу каждого класса и одна ранее существовавшая сцена без руки:

| Контрольный вход | HTTP | `result` | `reason` |
|---|---:|---|---|
| Размечен `incomplete` | 200 | `incomplete` | null |
| Размечен `complete` | 200 | `complete` | null |
| Пустая сцена | 200 | `uncertain` | `low_visibility` |

Один загруженный экземпляр, `model_version=rgb-motion-cnn-v1+95abbe0a8c77`, после запросов временный каталог пуст. Приватная `acceptance.json`, SHA-256 `77b28bfb4a3389ee27728e80793cadb6d03e36736792d87ccfdfd085c2a61af9`. Это те же development-люди, не независимая переоценка.
