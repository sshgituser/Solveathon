# Приватность контрольной сборки Qolda · 25 ноября 2026

**Решение для капитана:** в проверенном текущем дереве Git нет находок по перечисленным ниже признакам. Это не разрешение на открытие репозитория: его история сохраняет прежнее значение поля с машинным путём. Для публикации нужна отдельная проверка и решение капитана. APK проверен как файл, не как запущенное приложение.

| Объект | Проверенный результат | Ограничение |
|---|---|---|
| Дерево Git | Проверяются пути, форматы данных и признаки секретов. | Эвристическая проверка одной ревизии, не системных логов или чужих копий. |
| Android: точный контрольный APK | SHA-256 `23728fa2cbf260067f3f595366388b57cac1c263850b8564401015cea71786f2`. Независимое чтение ZIP: 95 уникальных записей, два графа TFLite, три native-библиотеки; ни одного файла с проверенными расширениями видео, дампов поз, исходных весов или приватных ключей. `aapt dump permissions`: пакет `net.qolda.offline`, только `android.permission.CAMERA`, без `INTERNET` и микрофона. | Состав архива и merged permissions; не динамический сетевой аудит. `installed=false`, телефонный GPU, паритет и полный автономный клип не подтверждены для этого APK. Это не APK Димаса. |
| Web / Windows API | Сервер привязан к `127.0.0.1`; обработчик проверяет Host/Origin и ставит `Cache-Control: no-store`. Обработчики E02/E03 используют временные приватные каталоги для входных файлов. Для [прогона E03](../platforms/shared-wip-e03-file.md) подтверждён пустой scratch после штатного завершения. | Loopback не авторизация от другого локального процесса. При аварии могут остаться временные данные. Системный сетевой трафик не измеряли. |
| Локальная история | В общем фронте `persist=false` по умолчанию. По исходникам `frontend/src/core/store.js` и `frontend/src/platform/storage.js`: настройки записываются отдельно; история сохраняется только при включении пользователем. Она может включать псевдоним, дневниковую заметку, метку результата и хэш записи для исключения повторов. Отключение сохранения удаляет ключ данных из `localStorage`, не настройки. | Хэш клипа и заметка не являются анонимными. Экспорт истории предназначен пользователю, не должен попадать в Git или командную квитанцию. Не проверено физическое стирание данных с носителя. |

Квитанция на ПК Димаса должна использовать SHA его собственных файлов, без сырых клипов, покадровых данных, полных логов и ключей подписи. Наличие файла, запуск, полный анализ и автономность — четыре разные отметки. [Сценарий и инструкция по запуску](../../docs/SUBMISSION.md).
